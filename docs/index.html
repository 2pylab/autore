claude-auto-resume

Claude Code의 5시간 사용량 제한에 걸리면, 리셋 시각까지 대기했다가 자동으로 작업을 이어가는 경량 감시 도구

Linux · macOS bash 3.2+ 텔레그램 알림 MIT License
지금 설치하기 GitHub 저장소

01기능

제한이 걸려도 잠이나 출근을 미룰 필요 없이, 리셋되면 알아서 작업이 다시 시작됩니다.

🔁 자동 재개

제한 감지 → 리셋 시각 파싱 → 대기 → 세션에 재개 메시지 자동 입력. 대화 맥락 그대로 복귀.

⏱ 다단계 시각 파서

3pm, 3:30 PM, 15:00, Jul 28 at 3pm(주간 제한), tomorrow at 9am, 자정/연도 넘김, 화면 줄바꿈 처리.

🛡 안전장치

같은 제한 메시지 중복 처리 방지, 모순된 시각 거부(제한 창 검증), 파싱 실패 시 주기적 재시도.

📨 텔레그램 알림

제한 감지 / 재개 완료 / 재시도 시 봇 알림 (선택 사항).

🧪 자가진단 내장

--selftest로 파서 단위 테스트 16종 실행.

📦 원라인 설치

의존성 검사 + 자가진단 포함 설치 스크립트. Linux와 macOS 모두 지원.

02설치

의존성: tmux, GNU date(macOS는 brew install coreutils), 선택적으로 curl(텔레그램용)

원라인 설치

curl -fsSL https://raw.githubusercontent.com/2pylab/claude-auto-resume/main/install.sh | bash

또는 클론 후 설치

git clone https://github.com/2pylab/claude-auto-resume.git
cd claude-auto-resume
./install.sh
명령설명
./install.sh~/.local/bin에 설치 (기본)
./install.sh --system/usr/local/bin에 시스템 전체 설치
./install.sh --prefix=경로지정 경로에 설치
./install.sh --uninstall제거

업데이트

claude-auto-resume update          # 최신 버전 확인 → 검증 후 교체 (자동 백업)
claude-auto-resume update --check  # 새 버전 확인만

다운로드한 파일은 문법 검사 + 자가진단 통과 후에만 교체되며, 기존 파일은 .bak으로 백업됩니다. 감시 실행 중이면 자동 중지 후 교체하니 업데이트 뒤 start로 다시 시작하세요.

03사용법

두 명령이면 끝 — 감시를 켜고, 평소처럼 Claude Code를 쓰세요.

claude-auto-resume start     # ① 백그라운드 감시 시작
claude-auto-resume attach    # ② Claude Code 세션 접속 → 평소처럼 작업
명령설명
start [옵션]백그라운드 감시 시작 (tmux 세션 없으면 자동 생성)
stop감시 중지
status감시 상태 + 세션 + 텔레그램 설정 + 최근 로그
logs [-f]로그 보기 (-f: 실시간)
attachClaude Code tmux 세션 접속
run [옵션]포그라운드 감시 (디버깅용)
update [--check]최신 버전으로 자동 업데이트 (--check: 확인만)
--selftest파서 단위 테스트 16종

주요 옵션 (또는 동명 환경변수)

옵션기본값설명
--session NAMEclaude감시할 tmux 세션명
--poll SEC30화면 확인 주기
--buffer SEC90리셋 후 여유 대기
--fallback SEC900시각 파싱 실패 시 재시도 대기
--max-resends N2같은 제한 메시지 최대 재전송
--message TEXT계속 이어서 진행해줘리셋 후 자동 입력 메시지
--dry-run—실제 전송 없이 로그만 (테스트용)

전체 옵션은 claude-auto-resume --help 또는 README 참조.

04텔레그램 알림 (선택)

제한 감지, 재개 완료, 재시도 때마다 텔레그램으로 알림을 받습니다.

1텔레그램 @BotFather → /newbot → 봇 토큰 발급
2봇과 대화 시작 후 @userinfobot 등으로 채팅 ID 확인
3~/.bashrc에 아래 두 줄 추가 후 start
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export TELEGRAM_CHAT_ID="123456789"
⚠️ 토큰을 --telegram-token 인자로 넘기면 ps 출력에 노출될 수 있으니 환경변수를 권장합니다.

05동작 원리

1tmux 세션의 Claude Code 화면을 30초마다 확인 (하단 40줄, 줄바꿈 메시지는 2줄 더 묶어서 파싱)
↓
2제한 메시지 감지 → 리셋 시각 파싱 (제한 창 밖의 모순된 시각은 거부)
↓
3리셋 시각 + 버퍼(90초)까지 대기
↓
4세션에 재개 메시지 자동 입력 → 텔레그램 알림
↓
5여전히 제한 상태면 최대 2회까지만 재시도 (메시지 도배 방지)

감지된 실제 제한 메시지 원문은 ~/.claude-auto-resume-samples.log에 자동 수집되어, Anthropic이 메시지 형식을 바꿔도 파서를 안전하게 업데이트할 수 있습니다 (--selftest 회귀 테스트 16종).
