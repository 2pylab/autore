claude-auto-resume

Hit Claude Code's 5-hour usage limit? This lightweight watcher waits for the reset and automatically resumes your work.

Linux · macOS bash 3.2+ Telegram alerts MIT License
Install now GitHub repo

01Features

No more babysitting the rate limit — when it resets, your session picks up where it left off.

🔁 Auto-resume

Detect limit → parse reset time → sleep → type the resume message into your session. Conversation context stays intact.

⏱ Layered time parser

Handles 3pm, 3:30 PM, 15:00, Jul 28 at 3pm (weekly limits), tomorrow at 9am, midnight/year rollover, and wrapped lines.

🛡 Safety guards

Dedupes identical limit messages, rejects implausible times (limit-window validation), periodic retry on parse failure.

📨 Telegram alerts

Bot notifications on limit detection, resume, and retry (optional).

🧪 Built-in self-test

--selftest runs 16 parser unit tests.

📦 One-line install

Installer with dependency checks and self-test. Linux and macOS supported.

02Install

Dependencies: tmux, GNU date (macOS: brew install coreutils), optional curl (for Telegram)

One-liner

curl -fsSL https://raw.githubusercontent.com/2pylab/claude-auto-resume/main/install.sh | bash

Or clone and install

git clone https://github.com/2pylab/claude-auto-resume.git
cd claude-auto-resume
./install.sh
CommandDescription
./install.shInstall to ~/.local/bin (default)
./install.sh --systemSystem-wide install to /usr/local/bin
./install.sh --prefix=PATHInstall to a custom path
./install.sh --uninstallUninstall

Updating

claude-auto-resume update          # check latest → verify → replace (auto backup)
claude-auto-resume update --check  # check only
Note for v1.0.0 users: update was introduced in v1.1.0. On older versions, re-run the install one-liner above once — afterwards you can use update.

The downloaded file is only installed after passing a syntax check and the self-test, and the previous file is backed up to .bak. If the watcher is running it is stopped first — run start again afterwards.

03Usage

Two commands — start the watcher, then use Claude Code as usual.

claude-auto-resume start     # ① start background watcher
claude-auto-resume attach    # ② attach to the Claude Code session → work as usual

05How it works

1Checks the Claude Code screen in tmux every 30s (last 40 lines; wrapped messages joined with the next 2 lines)
↓
2Detects the limit message → parses the reset time (implausible times outside the limit window are rejected)
↓
3Sleeps until reset time + buffer (90s)
↓
4Types the resume message into the session → Telegram alert
↓
5If still limited, retries at most 2 times (no message spam)

Every detected limit message is collected in ~/.claude-auto-resume-samples.log, so if Anthropic changes the message format, the parser can be updated safely (with 16 --selftest regression tests).
